# 阅读 Use Case、测试与概念

维护者在面板中打开一个 Feature 或 Use Case，读它的正文，查看实现它的代码和保护它的测试，并查询正文中概念的定义。

## 主流程

1. 打开 Feature，右栏显示正文，下方依次列出 Use Case、支持页面、实现与测试。
2. 打开 Use Case，显示所属 Feature、主流程与验收，下方列出关联的实现与测试。
3. 选中实现或测试，显示源码位置与声明所在的代码范围；测试另显示最近一次运行的命令、时间与结果。
4. 正文中出现 `concepts.md` 定义的概念时加以标记；选中后显示该概念的定义与解释。
5. 正文中指向工作区文档的链接在面板内打开，`Esc` 回到原来的位置。

## 验收

- Markdown 按终端文本呈现：标题层级、有序与无序列表、行内代码、代码块与表格可读；长行在宽度内折行，代码块保持原始行并可横向滚动。Mermaid 与 p5 图块显示源码与「在 Web 中查看」提示，不在终端执行脚本。
- 实现与测试关系与 Web 工作台的实现页、测试页一致，按 Feature 与 Use Case 分组，来自源码标记与代码关联。
- 测试状态取自 `concord test run` 记录的收据，分为通过、失败、未运行与过期；测试源码或其指向的 Spec 在收据之后改动的，标为过期。面板不把收据当作覆盖率或功能完成的证明。
- Feature 汇总自身、支持页面与所属 Use Case 的测试状态。
- 概念按目录作用域解析：同名概念在兄弟目录中各自定义时，显示适用于当前文档的那一个。使用弃用名的位置标记为弃用，并显示现行写法。
- 指向工作区外或不存在目标的链接显示目标原文，不伪装为可打开的页面。
