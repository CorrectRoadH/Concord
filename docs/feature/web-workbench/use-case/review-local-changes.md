# 查看本地未提交变更

开发者在 Git 工作区运行 `concord view`，打开显示的地址，直接看到尚未提交的变更。

## 主流程

1. 进入变更列表，默认查看全部文件，也可筛选文档或测试。
2. 选择文件，阅读统一或分栏差异。已暂存比较 HEAD 与 index，未暂存比较 index 与工作树，未跟踪显示新文件内容；同时存在多个区域时可以切换。
3. 修改文件后刷新。文件已无变更时选择仍可用的文件，没有变更时明确显示空状态。
4. 从侧栏进入契约、文档与其它工作台功能，编辑仍遵守摘要保护。

## 验收

- 暂存后继续编辑、新增、删除、重命名、模式变化、冲突、二进制与特殊文件名均有明确展示。
- 文档筛选包含重命名前或后位于 docs 的文件；测试筛选使用已配置测试根与声明。
- 未跟踪符号链接不读取链接目标；大文件明确标注预览限制。
- Git 展示不执行暂存、提交或 push，不将新增测试声明标为已经通过。
- URL 保留分类、文件、区域和差异布局。
