# 在 Web 里编辑写作规则与术语

## 用户目标

维护者想在 Web 工作台里浏览全项目术语、修改写作规则，不用记文件格式。

## 起始状态

- `concord view` 正在运行，浏览器打开了工作台。

## 完整路径

1. 打开侧栏的「术语」。 {#terms}

   左侧列出全部概念，可以按写法、定义和目录筛选；选中一个，右侧打开它所在的 `concepts.md` 并定位到这个概念，边改边显示格式问题。

2. 打开侧栏的「写作规则」。 {#rules}

   选择“整个项目”或某个目录，编辑长度上限和不用的词。没有局部 `writing.md` 的目录显示“沿用上级规则”。

3. 保存。 {#save}

   每份文件单独保存。文件在你打开后被别人改过时，保存被拒绝，草稿保留，并显示差异。

## 结果

保存的就是 `writing.md` 与 `concepts.md` 文件本身，和直接编辑效果相同。切换目录或离开页面时，未保存的草稿受保护。
