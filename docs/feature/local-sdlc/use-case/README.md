# 用户路径索引

- **接入并取得模板**：初始化配置、指南和参考模板，同时保留已有文档。
- **规划并采用文档契约**：维护完整文档 package，以唯一 owner 保存当前语义和历史。
- **发现测试并重建缓存**：只接受可绑定的 runner import 与紧邻注释，缓存损坏时回源。
- **记录命令证据并关闭 Problem**：签发受定义与候选摘要约束的 red/green 收据。
- **保护并恢复本地状态**：阻止路径逃逸、并发覆盖和不安全恢复。
- **追踪契约并生成审阅材料**：动态反查测试、Memory 和证据，不虚构覆盖率。
- **加载兼容的 Repository Profile**：校验 host 根目录与 engine identity，并保持 formal evidence 边界。

每条路径的验收条件写在对应 Use Case owner 中，真实测试关系由测试源码注释拥有。
