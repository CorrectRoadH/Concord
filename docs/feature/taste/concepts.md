# 品味术语表

本页定义品味文件与依据中的概念。[品味](../../concepts.md#taste)与[品味条目](../../concepts.md#entry)由[全局术语表](../../concepts.md)定义。

## 总则 {#general}

品味文件中 `## 总则 {#general}` 一节：以带 `{#general-<name>}` ID 的有序列表项写所有品味共同遵守的规则。

## 依据 {#citation}

页面在句子旁用行内链接指向品味条目的 ID，表示这句话依据那条品味。反向列表由 `concord taste` 从正文推导，不另外登记。

旧写法：`品味链接`

只有相对所在文件解析到品味文件、并带 fragment 的行内链接才是依据。
