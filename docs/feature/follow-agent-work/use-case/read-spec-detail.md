# 查看 Use Case、测试与概念

维护者在面板中选中一个 Use Case，读它的主流程与验收，查看保护它的测试是否通过，并查询正文中概念的定义。

## 主流程

1. 选中 Use Case，面板显示标题、所属 Feature、主流程与验收。
2. 详情下方列出关联测试：测试名、源码位置与最近一次运行的状态。
3. 选中测试，显示声明所在的源码范围与最近收据的命令、时间和结果。
4. 正文中出现 `concepts.md` 定义的概念时加以标记；选中后显示该概念的定义与解释，以及它所属的目录作用域。
5. `Esc` 返回列表，保持原来的选中项。

## 验收

- Markdown 按终端文本呈现：标题、有序与无序列表、行内代码、代码块与表格可读；链接显示目标，指向工作区文档的链接可以在面板内打开。长行在宽度内折行，代码块保持原始行。
- 测试状态取自 `concord test run` 记录的收据，分为通过、失败、未运行与过期；测试源码或其指向的 Spec 在收据之后改动的，标为过期。面板不把收据当作覆盖率或功能完成的证明。
- 概念按目录作用域解析：同名概念在兄弟目录中各自定义时，显示适用于当前文档的那一个。使用弃用名的位置标记为弃用，并显示现行写法。
- Feature 详情汇总自身、支持页面与所属 Use Case 的测试状态。
