# 来源与工程知识术语

结构化定义由 [全局概念目录](../../concepts.json) 与 [本 Feature 概念目录](concepts.json) 拥有。全局目录定义 Issue、Memory 和 Contract；本目录定义 Provider、Connection、Index 与 Recall，并显式引用全局概念。Concord 的 concepts 工具与 Web 写作页提供当前定义、允许别名、弃用名称及只读来源汇总。

Local 不需要 Connection。第三方来源的本地笔记与远端对象分别拥有状态；关闭本地观察不等于远端已关闭，也不等于 Memory 已修复。Index 和 Recall 从当前 owner 读取事实，不生成另一份人工登记表或新的执行证据。
