# 修改一页文档并检查

## 用户目标

维护者读 Spec 时发现一处要改，想当场改完并知道有没有弄断链接或用错词。

## 起始状态

- mod 正在显示 Feature `cart` 的 README。

## 完整路径

1. 点“编辑”，修改正文。 {#edit}

2. 点“保存”。 {#save}

   mod 写回文件，然后运行 `concord check`，在页面顶部显示结果：

   ```text
   check: ok
   ```

3. 检查报告 finding 时，结果列出文件和行，点一项跳过去。 {#fix}

   ```text
   check: 1 个问题
     docs/feature/cart/README.md:12  单子 → 订单
   ```

## 结果

文件已保存，检查结果就在眼前。

| 情形 | 结果 |
| --- | --- |
| 保存前文件已被 agent 改过 | 不覆盖，显示冲突并保留你的草稿；可以查看差异后重新合并 |
| 放弃修改 | 关闭编辑，正文恢复为文件当前内容 |
| 仓库在远程机器上 | 与本机相同，见[在远程机器的终端旁使用](use-on-remote-machine.md#edit) |
