# agent 改了文件，mod 自动刷新

## 用户目标

维护者让 agent 改 Spec 或代码，想看到最新内容，同时不打断自己正在读的地方。

## 起始状态

- mod 正在显示 Use Case“加入商品”，维护者滚动到了第 3 步。

## 完整路径

1. agent 修改了 `docs/feature/cart/use-case/add-item.md` 并加了一个测试。 {#agent-writes}

2. mod 在一秒内刷新。 {#refresh}

   正文显示新内容，测试列表多出新的测试；当前打开的文档与滚动位置保持不变。

## 结果

| 情形 | 结果 |
| --- | --- |
| 正在编辑的文件被 agent 改了 | 草稿保留，提示文件已变化；保存时按冲突处理 |
| 独立 Concord pane 所属 tab 不在前台 | 不等待变化；切回这个 tab 时立即刷新一次 |
| 布局侧栏打开时切换 tab 或 space | 跟随新 tab 的终端及其机器，重新读取仓库；不保留前一仓库的报错 |
| 两个 tab 指向同一仓库 | 切换后立即刷新，保留选中的文档与草稿 |
| 换仓库时仍有草稿 | 保留草稿，保存到原仓库或放弃后，再显示最新选中 tab 的仓库 |
| 仓库还没有初始化，在终端里运行 `concord init` | 等待期间初始化页面保持不动、不闪烁；初始化后 2 秒内显示文档列表 |
| 刷新得到的结果没有变化 | 界面什么也不动；有变化时新内容一次换上，不先闪出“正在读取” |
| 当前打开的文档被删除 | 显示“这页已被删除”，文档列表同步移除 |
| 仓库在远程机器上 | 在 2 秒内刷新，见[在远程机器的终端旁使用](use-on-remote-machine.md#follow) |
