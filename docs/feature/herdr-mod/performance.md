# Concord mod的性能测量

本页拥有 herdr-mod 的测量场景与预算，方法见[性能测量](../../engineering/performance/README.md#测量方法)。场景直接使用 Mitata，入口为 `bench/herdr-mod.bench.ts`。

## 测量场景

| 场景 | 测量内容 |
| --- | --- |
| `herdr-mod/page-source` | 解析实际页面正文中的文本与特殊内容块 |

计时边界为进程内真实操作与其自身资源释放，排除 CLI 宿主启动和格式化。固定输入、消费者与缓存状态由场景源码声明；修改这些条件时重新建立参照结果，不使用整进程数字作为操作预算。

Mitata 的成功退出表示测量完成，预算由交付者对照适用条件与原生统计判断。没有相同边界的参照证据时只报告测量结果，不宣称预算通过。

## 用户可见目标

页面模型解析不证明真实 Herdr 的加载、切换或推送时间。已初始化仓库的首屏与切入新仓库目标为 300ms，切回页面目标为 50ms，文件停止写入到可读描述更新的目标为 1000ms。它们需要真实事件边界的独立证据，不能用 `page-source` 的结果替代。
