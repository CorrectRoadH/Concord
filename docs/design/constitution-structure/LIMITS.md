# 宪法的结构、关联与写法

## L1: 运行时只接受当前格式

旧格式返回具名迁移诊断，由显式迁移命令处理，不提供兼容读取或双轨模型（[C-009](../../constitution.md#c-009)）。

## L2: 条款身份与修订历史保持

现有 `c-001` 至 `c-015` 的 ID 不变；修订记录的日期、顺序、理由、来源与影响原样保留（[C-008](../../constitution.md#c-008)）。

## L3: 迁移遵守写入契约

迁移校验路径与前像，在一个可恢复的变更集中发布，支持 `--dry-run`（[C-003](../../constitution.md#c-003)）。

## L4: 破坏性变更经独立审查

删除 `constitutionRefs`、`--constitution-ref` 与改变 `constitution show` 输出属于破坏消费者兼容，定案前完成独立审查（[C-007](../../constitution.md#c-007)、[C-015](../../constitution.md#c-015)）。

## L5: 不改变测试与代码关联

测试标记、代码声明的语法与合法目标集合不变（[C-011](../../constitution.md#c-011)）。
