# 宪法的结构、关联与写法

## G1: 引用精确到款且稳定

依据关系可以指向一款，插入、删除或重排其它款不改变已有引用。判定方法：CASES 中的 C1。

## G2: 断开的引用被 check 发现

纳入范围的行内宪法链接，目标不存在时 `concord check` 退出 1 并给出带行号的 finding。判定方法：CASES 中的 C2 与 C7。

## G3: 依据关系定位到句子且只声明一次

依据关系能定位到依据它的页面与行，包括附页；同一关系只在一处声明，反向视图派生。判定方法：CASES 中的 C3 与 C12。

## G4: 宪法只写规则

条款写法可以逐条审阅；实现机制、理由与过程不进入条款正文。判定方法：CASES 中的 C8。

## G5: 用 Concord 自己完成迁移与验收

本仓库通过 Concord 命令完成迁移，修复以 red 与 green 收据关闭。判定方法：CASES 中的 C9。
