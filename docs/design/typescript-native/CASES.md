# Cases

| Case ID | User Problem | Fixed Input | Acceptance Result |
| --- | --- | --- | --- |
| C1 | 静态配置安全 | 字面量、类型导入、函数调用、畸形语法 | 接受字面量；拒绝执行与语法错误；不加载项目代码 |
| C2 | 真实源码关联 | TS/JS/TSX 注释、字符串伪标记、区域、语法错误 | 保留标记范围、定位身份与具名诊断 |
| C3 | 依赖边界 | 捕获文件、tsconfig paths、缺失与动态导入 | 仅在捕获集合解析，未知项保留 gap |
| C4 | p5 沙箱 | 相对导入、类型导入、资源、错误类型、逃逸路径 | 类型错误与路径拒绝有效，无任意磁盘读取 |
| C5 | 生命周期 | 多次成功、失败、编辑器取消与 shutdown | 子进程、snapshot、lease 均释放，无进程全局泄漏 |
| C6 | 安装构建 | 打包包、隔离 Git 消费者 | 无全局 TS，公开 CLI 与声明可用，pnpm check 通过 |
