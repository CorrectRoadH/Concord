# 整体替换候选

## 方案

只接受可执行 TS 模块配置，立即迁移旧 JSON 消费者；Memory 采用跨目录与未来远端通用身份，统一重建引用与生命周期写入方式。

## 收益

允许完整 TS 模块表达能力与共享配置逻辑，后端扩展不局限当前 worktree。

## 代价与风险

查询会执行消费者代码，改变当前信任边界；任意外部依赖难以可靠纳入配置证据摘要。旧项目、journal、Memory 引用与历史证据需协调迁移；跨仓库 fixed 授权需新证据契约。回滚依赖数据修复，无法作为简单初始化 UI 改动交付。

## 状态

比较候选，未采用。本轮没有远端 mutation 或任意脚本加载授权。
