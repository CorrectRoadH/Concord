# HawDB 接入与 SQLite 移除

比较统一 HawDB 原生引擎和继续维护 SQLite/内存 Map。HawDB 候选包含短期解析缓存；来源 owner、证据和发布日志保持既有语义。方案采用以原生可行性和独立挑战为前提。
