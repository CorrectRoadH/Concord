# 多框架测试 adapter

## G1: 标记自动绑定到原生用例

在框架真实收集且有可验证源码范围的支持子集中，标记绑定到原生 leaf 或参数组。静态 AST 只能称候选声明。

## G2: 只执行选中的原生用例

精确选择不得执行未选 leaf。逐框架、版本、target 验收；动态子测试与重复全名不能仅凭模式宣称精确。

## G3: 收据能识别逐用例结果

记录完整 requested 与 observed，按共同契约统一裁决 green、red、invalid。报告不完整不能签发成功收据。

## G4: 原生标签可展示且不拥有关系

框架返回的标签可作元数据展示。标签中的契约字符串不创建关联；源码标记仍是唯一正向来源。

## G5: 新框架不修改 Concord 即可接入

受信外部程序通过有版本协议接入，严格解码与 Concord 裁决保持统一。扩展不改变最低证据要求。
