# 变更审阅约束

## L1: 公共阅读不授予本地能力

PR 读者不得获得仓库写入、测试执行、凭据或源码执行能力。约束来自 C-003、C-007；用恶意 Markdown 和 mutation 请求验证。

## L2: 产物绑定明确输入

固定完整 base/head/merge-base 身份。缺失历史、多个共同祖先或预算超限时具名失败，不回退默认分支或交付未标识的部分结果。约束来自 C-001、C-004。

## L3: 独占输出并保留未知文件

只能在受信父目录创建显式新目录；拒绝 symlink 祖先、Git-private 路径和目标冲突。失败与取消回收子进程与私有临时目录，保留不完整输出供调用者检查，不能删除未知文件。约束来自 C-003。

## L4: 可安装且有界

执行使用严格 TypeScript、Effect 和 Schema；消费者不依赖相邻仓库、全局安装或 Rust 编译器。读取与产物预算明确，测试从打包安装后的 CLI 进入。约束来自 C-002、C-005、C-006、C-014。
