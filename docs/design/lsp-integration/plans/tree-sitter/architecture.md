# tree-sitter

## 宪法与分发边界

本候选要求为固定随包的 WASM runtime 与 grammar 定义 C-005 许可边界，故在 C-005 不修订的契约下不可选。第三方预编译依赖与 Concord 维护的实现分别判断；本候选不维护自有原生 grammar 或项目动态编译路径，不把 WebAssembly 自动当成 HawDB 原生例外。

发行清单须固定 runtime、grammar、查询与字节摘要，并包含来源 revision、许可证、再分发条件及声明 notice。许可证缺失或不能随包分发时拒绝该语法。TypeScript/Effect 拥有 Schema 校验、符号绑定、资源回收与测试；消费者不提供 WASM、查询脚本或 native 插件。

## 绑定与配置

`sourceLanguages` 每项仅声明内置 `language` 与非空 `extensions`；注释前缀属于随包语言 profile，不声称配置可随意增加它。扩展名不得重叠或包含 JS/TS 变体；profile 按固定版本定义函数、方法、类型的语法节点与前置注释、装饰器规则。

从整个标记块结束处选择最近可绑定节点，优先最深声明，避免类内方法绑定到类；语法查询必须覆盖真实节点，不能仅以文本名称推断。语法错误、节点歧义或超预算时符号不可用，保留源码关系与标记行，不以解析器缓存状态生成关系 finding。

代码关联身份和符号 locator 严格分离，沿用共同契约。JS/TS 继续使用内置编译器，不改现有引用与声明有效性。

## 数据流

1. 关系扫描从当前源码重建标记及其目标，独立于 WASM 投影。`check` 不读取分析观察；符号解析失败不改变同一源码的关系结论。
2. 定位查询在固定 grammar/query 上解析目标文件，产生可丢弃的范围；无有效范围时显示标记行。静态定位不遍历模块或执行项目程序。
3. 跨文件 import 只在显式 `code analyze` 中形成共同 `Observation<T>`；逐语言模块解析需要单独的已验证策略，不以解析成功冒充闭包完整。
4. 文件级 import 命中实现声明时显示带 `FileScope` 的 `observed`，不等同实际调用。未命中显示带 `gaps` 的 `not-observed`；动态加载、未解析模块和外部边界均不能推出行为无关。

若与 LSP 组合，静态层提供定位，LSP 只补充[正向调用观察](../lsp-client/architecture.md#调用观察)，二者均不能改变关系身份。组合仍含相同 WASM 运行边界，需相同 C-005 修订，不构成可直接采用的替代方案。

## 预算

固定 WASM 内存页上限、文件字节、语法节点、查询匹配数与解析耗时上限；分配前校验，超过上限返回 `SyntaxBudgetExceeded`。使用可中断解析与受管实例，不把无法取消的同步解析称为有界超时。

实例不开放网络或任意文件系统导入，只接收已读入的目标字节与受限内存接口；每次解析结束、取消或失败均释放树、查询游标和实例资源。模块解析按安全仓库路径读取，不扩展 WASM 权限。

## 身份与复用

定位输入包括文件路径与字节、完整标记集合、grammar/runtime/query/profile/算法版本及预算。跨文件观察还包含成员集合、全部解析配置与依赖字节、契约和环境身份；任一输入改变使相应分析单元失效。

固定字节仅能证明语法树与查询结果的受限确定性，不能证明模块解析、依赖闭包或测试相关性完整。历史投影遵循共同 `Observation` 的时间、当前性与缺口规则，缓存损坏或清空不影响源码身份与关系。
