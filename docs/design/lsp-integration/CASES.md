# LSP 集成

## 验收边界

使用构建并打包后的公开 CLI，在隔离 Git 消费者中运行。可控 LSP 进程模拟协议边界与异常，不复制 Concord 的绑定、版本或判定实现。声明具体语言支持前，还须对该 server 固定版本运行真实语言 fixture；不调用付费模型，不以收据数量或协议 fake 代替兼容证据。

## 场景

| 场景 | 输入与操作 | 验收结果 |
| --- | --- | --- |
| C1 | Python、Go、Rust、Java 各有函数、类内方法、装饰器与同名声明；显式 `code analyze` | 支持 profile 的声明定位到最近正确节点；不能验证时标记行加 `UnsupportedSymbolBinding`，关系仍存在 |
| C2 | 同一源码在冷缓存、热缓存、缓存损坏和清空状态运行 `check`、`code list` | `check` 退出码、finding 与 `complete` 及当前关系和关联 ID 相同；只有可选 locator 与观察状态变化 |
| C3 | 测试经 `testRoots` 中的中间函数调用实现同一步骤的代码 | 不在遍历时过滤中间节点；观察到交集为 `observed` 且 level 为 `step`，保留 `OpenWorldCalls` |
| C4 | Rust 测试只观察到其它 Feature 的实现 | `not-observed`，显示“未观察到交集”及缺口，不产生行为无关结论或 finding |
| C5 | 目标在默认深度 3 之外，或能力缺失、空/null、动态调用、框架回调、子进程边界 | `not-observed` 带对应缺口；部分已观察命中仍为 `observed`，但 `complete` 为 false |
| C6 | server 启动失败、超时、取消、超输出，或主进程退出但子进程仍存活 | 具名失败；验证整个进程组与管道清理；未知清理保留 runner 阻断，不发布新快照，旧结果只作历史 |
| C7 | 编辑器同时未保存地修改步骤 ID 与测试引用，再补全、跳转和悬停 | 全部使用同一 overlay 依赖版本；引用新 ID 有效，不从旧磁盘图发出 `StepNotFound` |
| C8 | 新版本确实引用不存在步骤，随后旧版本分析延迟返回 | 当前版本发布缺失诊断；旧结果淘汰，不覆盖或清空新诊断；不完整输入不发布完整通过状态 |
| C9 | 在步骤上查引用；同时保存、关闭、删除、重命名或重新打开关联文件 | 返回同版测试和代码标记位置；保存不覆盖 overlay，关闭清诊断，旧 URI/打开代次任务失效 |
| C10 | 固定源码、profile、server 实现与可复现环境，清空后重新分析 | 关系与身份相同；按兼容 fixture 比较 locator 与观察。环境或索引不能核验时明确历史或缺口，不承诺无条件相同 |
| C11 | server 返回扁平符号、null、越界范围、错误嵌套，以及非 BMP 文本位置 | 不从扁平结果构造层级；按协商编码正确换算，默认 UTF-16；非法范围拒绝定位且保留关系 |
| C12 | 分析期间修改转调文件、fixture、配置、成员集合或 `node server.js` 的实际脚本 | 整个分析单元失效并拒绝当前发布；不能只核验目标文件或启动器字节 |
| C13 | 当前原生清单的范围/绑定/选中集合发生变化，或不存在有效原生范围 | 观察输入身份变化；无范围采用文件级并标 `FileScope`；测试 v1 关联 ID 与 `check` 关系不变 |
| C14 | 带 `@name` 的测试修改契约目标；仅有原生 tag 的测试含错误路径 | 命名关联 ID 按 v1 保持；源码目标关系更新，旧证据不可复用；tag 不新增关系，LSP 不签发收据 |
| C15 | server 发 `workspace/applyEdit` 或执行请求；第三方 server 自行修改项目文件 | 协议编辑/执行请求拒绝；项目副作用由输入重验检出，不把进程管理称作沙箱 |
| C16 | 显式分析与测试收集争用 runner，或文档在分析期间发布后恢复原字节 | 遵守 runner 所有权及失效标记；不持来源句柄等待进程，清理后重验，失效 run 不发布当前观察 |
| C17 | 编辑器依赖版本倒退、取消请求、磁盘配置漂移、非安全 URI 与迟到响应 | 拒绝非法输入、淘汰响应或标不完整；退出会话释放任务与句柄，不持久化 overlay |
| C18 | 任意静态入口、`test run` 或编辑器服务读取关系 | 不启动 language server；`check` 不读取观察，历史展示携带时间、来源、当前性与完整性 |
| C19 | tree-sitter 候选包含固定或项目上传的 WASM；组合候选另加 LSP | C-005 不修订时不可选；不加载项目 WASM，组合不绕过相同宪法边界 |

## 跨 Design 验收

步骤识别、标题 anchor 兼容与验收条目排除遵守共同契约，在编辑器 overlay 与磁盘扫描采用同一抽取规则。原生参数组缺失、跳过、重复与额外结果按共同收据规则验收，由 test-adapters 拥有；这些结果不授权 LSP 改写测试身份或签发证据。
