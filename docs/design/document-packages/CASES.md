# 文档目录与历史格式迁移

| Case ID | 输入 | 可观察结果 |
|---|---|---|
| C1 | 仅提供 Research 名称与标题 | 创建主题入口，无预设章节、来源或日期 |
| C2 | 在主题中添加中文、多级 Markdown 页面 | 可保存、刷新、定位，父主题不能修改嵌套独立 owner |
| C3 | 研究单文件含入站、出站及带 anchor 的链接 | 迁移后仍指向同一对象与 anchor，历史定位保持原值 |
| C4 | README、单文件与嵌套 Research owner 混合 | 所有原身份、正文、日期和来源保留，层级可浏览 |
| C5 | Engineering、Roadmap、Design 混有模板与导航 | 真实主题完整发现，候选和模板不重复成为主题 |
| C6 | 明确取消、明确暂缓、已选与未决的原文 | 不编造采用、选择或事件日期 |
| C7 | 计划后新增文件、配置变化、目标冲突或 publication 中断 | 零写拒绝或按原像恢复，未知编辑保留 |
| C8 | 重复应用迁移与删除缓存 | 幂等核对，结果不依赖迁移收据或缓存才能发现 |
