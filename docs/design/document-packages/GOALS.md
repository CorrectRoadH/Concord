# 文档目录与历史格式迁移

## G1: 已有主题完整发现

已有主题可以从 CLI 和 Web 完整发现；模板和导航不伪装为独立 owner。来源：原设计目标。验收使用[固定场景](CASES.md)，从打包 CLI 和实际 Web 入口核对。判定依据是固定场景从打包 CLI 和实际 Web 入口核对发现结果。

## G2: 研究正文自由组织

研究正文、章节和附页自由组织，不要求外部来源或观察日期。来源：原设计目标。判定依据是研究创建和迁移不强制研究提纲、来源或日期。

## G3: 保留身份来源历史与引用含义

已有身份、来源、历史和当前引用不因结构调整丢失或改变含义。来源：原设计目标。判定依据是迁移清单和固定场景保留 canonical identity、历史与当前引用。

## G4: 迁移冲突可拒绝或恢复

未知编辑、目标冲突、配置变化与中断都有明确拒绝或恢复结果。来源：原设计目标。判定依据是输入漂移、冲突、共享 journal 和恢复场景。

## G5: 历史状态可辨认

已取消、已暂缓、已选择与未裁决的历史状态保持可辨认。来源：原设计目标。判定依据是迁移审计是否保留原文明示状态而不推断未知裁决时间。
