# 保留旧单文件

仅让新研究使用目录，旧研究仍按原文件作为 owner。迁移较少，但形成两套模型，旧数据仍不能获得一致的目录入口；不满足统一目录体验，未选择。

## Limits

| Limit | Status | Mechanism or gap | Evidence |
| --- | --- | --- | --- |
| [L1](../../LIMITS.md#l1-路径拥有-canonical-identity) | satisfied | 旧文件继续作为 owner，未删除既有身份。 | 原候选正文明确保留旧研究文件 owner。 |
| [L2](../../LIMITS.md#l2-现有格式与链接不可静默丢失) | pending | 少量迁移减少改动，但原候选正文未定义链接基准变化的完整处理。 | 缺少相对链接重定向证据。 |
| [L3](../../LIMITS.md#l3-研究组织自由且不新增登记表) | not-satisfied | 同时形成目录和单文件两套模型，组织规则不统一。 | 原候选正文明确记载两套模型。 |
| [L4](../../LIMITS.md#l4-保留现场并使用可恢复发布) | pending | 原候选正文未说明前像、锁和 journal 发布协议。 | 缺少恢复边界证据。 |
