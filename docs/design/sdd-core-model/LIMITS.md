# 以 Spec 驱动开发的核心模型

## L1: 只有当前格式

不提供迁移命令、兼容读取或双轨模型；本仓库与接入项目直接改写为新格式（[C-009](../../constitution.md#c-009-1)）。

## L2: 修复可以复现

缺陷标记为已修复时，必须有一个能被任何人重新运行的检验，表明同一测试在修复前失败、修复后通过（[C-004](../../constitution.md#c-004)）。

## L3: 工具写入保护前像

Concord 执行的写入继续使用整文件摘要与 publication 协议，不覆盖外部编辑（[C-003](../../constitution.md#c-003)）。

## L4: 关系从来源派生

反向关系与索引从文件和标记派生，不维护第二份登记表（[C-001](../../constitution.md#c-001-3)）。
