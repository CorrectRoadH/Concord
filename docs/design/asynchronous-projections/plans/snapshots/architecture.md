# 异步投影与短提交

## 读取与查询

来源读取不创建 shared publication owner。扫描记录读取文件、缺失路径和目录集合，在返回前重新验证；发布代次变化使扫描返回 SourceChanged。未完成 journal 不产生当前成功结果。

trace show、trace gaps 与 review render 默认返回已完成的历史投影，并请求后台刷新。输出携带快照时间、刷新状态和非当前事实标识。首次无缓存返回 QueryPending，不把空结果解释为没有问题。--fresh 显式等待当前来源计算；check、trace check、作者读取与证据裁决总是使用当前来源。

缓存命中不加载 Repository，不等待 publication lease。投影键绑定 worktree、命令参数与实现身份；查询投影在 HawDB 独立命名空间内严格解码。配置身份变化不能复用旧配置下的投影。数据库暂时不可读时报告不可用，不在前台执行全量扫描。

## 后台刷新

同查询键只有一个活跃刷新 owner，死亡 owner 可回收；合并只控制刷新，不限制查询或文档发布。后台进程只运行允许缓存的只读查询，关闭继承的终端输入输出，运行时间受异步查询契约的刷新上限约束。后台来源扫描关闭持久解析缓存，避免在计算期间占用服务查询投影的数据库；Schema、摘要和路径核验保持执行。刷新成功时短暂打开数据库，在事务内替换该键的完整结果；缓存占用按有界重试处理。刷新失败保留上一份结果；数据库可写时在同一条记录内保存具名错误；缓存清理不删除来源或证据。

## 写入与恢复

普通写入规划不取得独占 lease。提交前获取短期独占所有权，重读配置、观察集合及完整前像，持久化 journal 后逐文件发布。并发写者以冲突失败，不覆盖未知修改。发布开始与结束推进随机代次，读取无需登记自身 owner。

恢复、多文件事务与证据签发仍按既有互斥及清理边界执行。runner 的生存与隔离、HawDB 的目录所有权不由查询缓存替代。不支持混合协调协议的可执行文件同时操作同一 worktree。

## 验收

真实独立 CLI 验证缓存首次构建、退出后刷新完成、命中返回、来源变更后的历史标识、--fresh 当前结果、并发写入不被扫描阻塞、刷新失败保留旧结果，以及两个写者冲突。并发来源变化不能生成有效当前快照，check 与 fixed 不消费历史投影。

具体的重试时长、输出上限、合并与入库条件、刷新上限和读取预算由[读取异步刷新的诊断投影](../../../../feature/local-data-engine/use-case/query-asynchronous-projections.md)拥有，本方案不重复声明。
