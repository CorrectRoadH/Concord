# Cases

- Two repository objects prepare independently; commit sections contend.
- Read-only dependency, missing file or scanned directory changes before commit.
- Process exits during publication; recover preserves an unknown external edit.
- Two recoverers observe one dead token while a fresh writer arrives.
- Claim or release fails, owner metadata is unknown, or PID presence is uncertain.
- A long test runs while an unrelated document is published; candidate changes cannot issue current green evidence.
- Built and packed CLI runs with no external lock or disk commands.
- Cache deletion, unsafe paths and linked-worktree isolation.
