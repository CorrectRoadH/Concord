# 测试关联到 Use Case 步骤

## L1: 正向关系只由源码标记拥有

正文拥有步骤，源码拥有正向关联。反向视图从两者派生，不存第二份登记表（[C-001](../../constitution.md#c-001)、[C-011](../../constitution.md#c-011)）。

## L2: 派生结果不表达证据

步骤关联和观察交集不证明执行、断言正确或覆盖率，不用于 fixed（[C-004](../../constitution.md#c-004)）。

## L3: 契约正文只写声明

正文只维护步骤与行为；展示状态不写回正文。步骤 ID 在两条写作路径中均排除（[C-012](../../constitution.md#c-012)）。

## L4: 只接受当前格式

测试关联保持共同契约的 v1。命名测试改目标可保持 ID，annotation 与 contract 摘要使旧收据失效；旧原件保留且重新取证（[C-009](../../constitution.md#c-009)）。

## L5: 相关性判定不执行项目代码

静态入口和编辑器不产生观察。check 只读取正文及源码关系，不读取分析快照；视图可以读取标明时效的观察（[C-010](../../constitution.md#c-010)、[C-013](../../constitution.md#c-013)）。
