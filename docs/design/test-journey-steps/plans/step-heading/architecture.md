# 步骤标题导航

## Entity Ownership

步骤领域集合与[共同身份](../../共同身份.md)完全相同。正文使用顶层有序项与显式 ID；标题只呈现导航，不定义第二种步骤身份。验收条目按共同契约不得使用步骤语法；合法顶层标记位于任意章节时均按步骤解析。嵌套项与其它 owner 中的真实步骤语法按共同契约产生 `InvalidStepPosition`。

## 书写与呈现

作者在步骤第一段末尾声明 ID；Concord 在侧栏把第一段摘要呈现为标题导航，选中后滚动到原列表项。摘要从正文派生，可截短，不参与引用身份，不写入 Markdown。普通 H3 即使有显式 ID 也仍是非步骤 anchor。

纯 H3 替换列表的变体不能满足共同契约，不属于可采用机制。候选比较的是直接列表展示与额外标题导航的阅读方式，不依赖“主流程”等章节文字。

## Data Flow

正文解析、命名空间冲突检测、引用兼容、ordinal、观察提供者、错误与证据失效规则均遵守[列表项架构](../step-anchor/architecture.md)。侧栏只从步骤集合派生，不加载项目进程。

## Invariants

没有列表项 ID 就没有步骤。导航标题改写不会改变 ID；删除步骤 ID 后引用失败。非步骤标题、整个 Use Case 保留独立分组。check 不读取观察；相关性只为共同契约的 observed 或带 gaps 的 not-observed。

## Identity and Reuse

v1 测试关系身份、独立的原生选择身份与观察时效均引用共同契约。标题摘要及其顺序是可重建展示字段。
