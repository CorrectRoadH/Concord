# 受控写作规则

## G1: 程序性与描述性文本使用不同阈值

政策分别设置两类文本的句长上限与每段句数上限。验收检查 AST 类型与嵌套段落是否只计一次。

## G2: 中文与英文分别计数

controlled 使用确定的分句、语言策略与 token 规则。legacy 保留字符路径；行内代码、数字、混排与步骤标记都有确定结果。

## G3: 程序性句子只写一条指令

可选词法检查报告受控动作词的出现次数。它只能部分支持此目标，不能据此证明指令数量；finding 写“命中多个受控动作词”。

## G4: 程序性动词来自项目词表

可分别开启“至少命中一个受控动作词”与英文批准词检查。缺少命中只说明词面未命中，不能证明句子没有动作或用了未批准动词。句首大写词仍接受批准词检查。

## G5: 报告被动语态

可选规则报告英文助动词与指定分词相邻的模式，以及中文字符“被”的命中。finding 不断言语法事实；政策可声明按规则、按语言的字面豁免。
