# 实现声明自动派生查询引用

保留无参数的范围标记和显式 `@concord-implements`；Concord 在扫描时从源路径与结构位置派生查询引用。维护者不需要另行命名。

引用服务于当前查询；它不承诺重构前后身份连续，不进入证据。生成片段时尚未确定源码位置，因此不返回虚构的声明身份。

## Limits

| Limit | Status | Mechanism or gap | Evidence |
| --- | --- | --- | --- |
| [L1](../../LIMITS.md#l1-源码是唯一-owner) | satisfied | 源码拥有实现关系，扫描从源码派生，不增加登记表、sidecar 或 UUID 写回。 | 原候选正文明确保留源码声明和无额外命名。 |
| [L2](../../LIMITS.md#l2-不改变相邻协议或证据含义) | satisfied | 引用只服务当前查询，不进入证据，生成片段不返回虚构身份；普通扫描不改写源码。 | 原候选正文明确描述当前查询和源码不写回边界。 |
| [L3](../../LIMITS.md#l3-只实现当前-concord-协议) | satisfied | 保留无参数范围标记，不引入旧命令兼容或迁移机制。 | 原候选正文及裁决明确项目尚未发布且不承担兼容。 |
