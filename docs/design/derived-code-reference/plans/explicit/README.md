# 实现声明自动派生查询引用

继续使用手写 ID，或由工具生成 UUID 后写回范围标记。位置移动可以保留身份，但每段声明仍需要额外的身份字段与复制/冲突维护；不满足用户取消源码身份定义的目标。

| --- | --- | --- | --- |
| [L1](../../LIMITS.md#l1-源码是唯一-owner) | not-satisfied | 手写 ID 或 UUID 写回会增加源码之外的身份维护负担。 | 原候选正文明确要求额外身份字段与维护。 |
| [L2](../../LIMITS.md#l2-不改变相邻协议或证据含义) | pending | 原候选正文未说明测试、Memory/evidence、配置和恢复协议边界。 | 缺少相邻协议证据。 |
| [L3](../../LIMITS.md#l3-只实现当前-concord-协议) | pending | 原候选正文未说明旧命令、兼容层或外部项目修改边界。 | 缺少当前协议范围证据。 |
