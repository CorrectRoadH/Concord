# 实现声明自动派生查询引用

## G1: 维护者只声明范围与契约关联

维护者只声明范围与契约关联，不命名、分配或复制实现身份。片段生成和 Web 添加关联不要求 ID；关联目标继续由维护者明确提供。来源：原设计目标。判定依据是候选是否不要求手写身份，同时保留维护者明确关联目标的责任。

## G2: 工具可查询、反查并定位实现

工具仍能查询当前实现、反查契约并定位源码。来源：原设计目标。判定依据是候选是否保留当前扫描、查询和反向定位能力。

## G3: 派生引用在稳定编辑和扫描环境中稳定

重复扫描、行号与空白变化不使引用抖动；命名函数体和关联目标的普通编辑不改变其引用。来源：原设计目标。判定依据是候选是否描述这些稳定性条件。

## G4: 结构位置可区分且可重建

同文件同名方法、嵌套作用域和多个 region 可区分，复制实现不造成手写 ID 冲突；缓存清空、进程重启和同内容新 clone 可重新派生相同引用。来源：原设计目标。判定依据是候选的结构定位和可重建机制。

## G5: 明确永久身份边界并保留现有入口

清楚说明重命名、文件移动、匿名或同描述节点顺序变化不具有永久身份保证。三种范围、Engineering、trace、review 和 Web 保留；CLI 只提供有用的发现、定位与注释生成入口。来源：原设计目标。判定依据是候选是否明确这些边界和入口。
