# 实现声明自动派生查询引用

维护者只声明范围与契约关联，不命名、分配或复制实现身份。工具仍能查询当前实现、反查契约并定位源码。

- 片段生成和 Web 添加关联不要求 ID；关联目标继续由维护者明确提供。
- 重复扫描、行号与空白变化不使引用抖动；命名函数体和关联目标的普通编辑不改变其引用。
- 同文件同名方法、嵌套作用域和多个 region 可区分，复制实现不造成手写 ID 冲突。
- 缓存清空、进程重启和同内容新 clone 可重新派生相同引用。
- 清楚说明重命名、文件移动、匿名或同描述节点顺序变化不具有永久身份保证。
- 三种范围、Engineering、trace、review 和 Web 保留；CLI 只提供有用的发现、定位与注释生成入口。
