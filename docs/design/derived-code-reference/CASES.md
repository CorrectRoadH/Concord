# 实现声明自动派生查询引用

| 场景 | 输入与操作 | 验收结果 |
|---|---|---|
| C1 | 为文件、函数、region 关联契约 | 无须输入 ID；显式关联与范围完整保留 |
| C2 | 增加空行、注释，编辑命名函数体或关联目标 | 同一节点引用保持相同，当前位置更新 |
| C3 | 两个类都有 run 方法、嵌套函数同名、复制节点或文件 | 当前引用唯一；同描述兄弟序号变化的边界明确 |
| C4 | 移动文件、重命名、在前方新增 region | 返回新的当前引用，不假装具有永久身份 |
| C5 | 清缓存、重启、新 clone 同一源码 | 无登记表仍可重建相同当前引用 |
| C6 | 缺少 end、嵌套 region、半表达式、字符串伪标记 | 保持原绑定与边界检查，不能静默生成错误关系 |
| C7 | 范围标记带多余参数 | 按当前语法拒绝无效注释，扫描不写源码 |
| C8 | Feature、Use Case、Engineering，含页面与 anchor | query、trace、review 和 Web 保留 exactRef 与正确归属 |
| C9 | annotate/list/locate 及片段 action | 无需身份输入，不提供按 ID 查询入口 |
| C10 | 代码声明错误与测试证据流程同时存在 | 测试执行和 Memory fixed 不新增代码前置条件 |
