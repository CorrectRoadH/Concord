# 工作区只读投影

## Decision

Selected: [shared-projection](plans/shared-projection/README.md)

## Rationale

同步扫描在 C1 中会把普通编辑变成 409，C2 可因连续漂移一直没有可用导航。共享结构投影使 HTTP 读取与全量扫描解耦，旧代次在刷新失败时可读；首次无代次时明确构建中，并允许有界扫描发布标注不完整的导航。C4 的前像只来自定向当前文件读取，旧投影无写入权限。C3 同时保留现有 CLI 当前查询并提供显式缓存视图。C5 只设一个服务进程刷新 owner，缓存失败直接具名不可用。候选表中的“满足”表示方案机制满足约束，不代表实现验收通过。

## Rejected Options

Web 专属投影不能让 CLI 查看同一展示代次，不满足 L3/G2。同步扫描继续让来源漂移阻断导航，不满足 L6/G1/G4。二者均不采用。

## Residual Risks

不完整代次可能遗漏跨文件关系；界面必须将未知显示为未知，验收以连续改写下的 C2 负例为准。结构投影容量和原生锁争用需在打包消费者上测量 C5，并为超限给出具名失败。缓存中不得出现正文，须检查实际持久 payload。配置与安装身份变化必须使旧记录失效。独立 Opus 5.5 Review 的结论为 PASS：漂移分类、一致性与诊断分离、独立缓存配额和恢复入口满足设计边界。该结论不代替实现及打包消费者验收。宪法 C-014.4 明确允许有标注的不一致导航投影。
