# 依据品味写作和审阅

## 用户目标

作者想说明一处写法依据的是哪条品味；审阅者想知道某条品味被哪些页面依据，以便评估修改它的影响。

## 起始状态

- `docs/taste.md` 中有 `T-1 读得懂胜过写得全`。
- Feature `cart` 已存在。

## 完整路径

1. 在依据品味的句子旁链接它。

   ```markdown
   细则放在 cli 页，README 只讲能做什么（[T-1](../../taste.md#t-1)）。
   ```

2. 查看哪些页面依据这条品味。

   ```sh
   concord taste
   ```

   预期输出：

   ```text
   T-1 读得懂胜过写得全
     docs/feature/cart/README.md:12
   ```

3. 审阅时指出不合品味的地方。

   审阅意见直接链接品味条目，例如“这段把退出码写进了 README，不合 [T-1](docs/taste.md#t-1)”。品味是判断标准，`check` 不判断正文是否符合品味。

## 结果

依据关系写在句子旁，反向列表由 `concord taste` 从正文推导，不另外登记。
