# 项目后台术语表

## 操作票据 {#operation-ticket}

后台在执行前签发的一次操作的身份，由服务实例与操作 ID 组成。重复提交同一票据只观察原操作，不能产生第二次执行；它不证明操作成功，也不能跨后台重启恢复执行。

## 执行上下文 {#execution-context}

一次请求所使用的项目目录与调用环境。它在请求作用域内固定，供对应操作读取配置、启动程序和取得凭据；不作为其它客户端的默认环境。

## 命令作用域后台 {#command-service}

由一条 CLI 命令拥有、随该命令结束而回收的项目后台。它使用同一服务实现和项目锁，只为所属命令及其受管子调用服务。
