# 共享工作区服务术语表

本页定义多客户端共享操作中的概念。[工作区服务](../../concepts.md#workspace-server)与[项目目录](../../concepts.md#project-directory)由[全局术语表](../../concepts.md)定义。

## 操作票据 {#operation-ticket}

工作区服务在执行前签发的一次操作的身份，由服务实例与操作 ID 组成。重复提交同一票据只观察原操作，不能产生第二次执行；它不证明操作成功，也不能跨服务重启恢复执行。

## 执行上下文 {#execution-context}

一次请求所使用的项目目录与调用环境。它在请求作用域内固定，供对应操作读取配置、启动程序和取得凭据；不作为其它客户端的默认环境。
