# Roadmap

Roadmap 保存尚未成为当前契约的产品方向。它和 Feature 使用同一种体裁：README、Use Case、cli 等页面按同样的方式书写。方向进入 Roadmap 而不是 Feature，原因是设计还不完整，或者已经设计好但暂不安排实现。`roadmap adopt` 复制完整 Markdown package、迁移 current promotion 并保留 adopted 历史；采用后契约由新 Feature 拥有。

使用 `concord roadmap list` 查看待采用方向，`concord roadmap create --help` 创建。
